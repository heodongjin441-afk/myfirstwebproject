HTML

HTML이란?

html은 웹사이트에서 기본 뼈대가 되어주는 역할입니다.

HTML 기본 구조

head body의 형식이다.

태그와 요소

몇가시 예시로 든다면

h1태그는 제목 태그이다.

p태그는 본문 태그이다.

시맨틱 태그

시맨틱 태그는 header, main, footer로 나뉘어진다 header는 웹 사이트의 맨 위이며 main은 본문 footer는 맨 마지막에 쓰인다.

form / input

input태그는 사용자가 데이터를 보낼 때 쓰이는 태그이다.

form 태그는 사용자가 입력한 데이터를 하나의 묶음으로 만들어 서버에 보내주는 태그이다.

CSS

CSS란?

웹사이트의 살과 피부가 되어주는(디자인) 역할이다.

선택자

.은 class 선택자, #은 id의 선택자이지 그리고 일반 태그 선택자는 h1{}이런 형식으로 디자인 하면 된다.

Box Model

하나의 크기와 여백 구조

content → padding → border → margin

Flexbox

여러 요소를 "어떻게 배치할지" 다루는 레이아웃이다.

Grid

사용자가 원하게 여러개의 열로 배치가 가능하며 반응형으로 자리가 부족하면 자동으로 열을 늘려주는 기능도 있다.

const 변수명 = 'abcd'의 형태이다, 또한 let, const 변수 선언 문에는 각각 다른 기능이 있다.

조건문

반복문

for(let i =0;i<100;i++)의 형식이다.

함수

HTTP

HTTP란?

HTTP는 HyperText Transfer Protocol의 약자로, 웹에서 데이터를 주고받기 위한 프로토콜입니다.

Request

클라이언트가 서버에 요청을 보내는 과정입니다. 브라우저에서 URL을 입력하거나 링크를 클릭하면 요청이 발생합니다.

Response

서버가 클라이언트에게 응답을 보내는 과정입니다.

GET / POST

GET은 서버에서 데이터를 가져올 때 사용하고, POST는 서버에 데이터를 전송할 때 사용합니다.

Cookie / Session

Cookie는 클라이언트 측에 저장되는 작은 데이터 조각이며, Session은 서버 측에서 관리되는 사용자 세션 정보입니다.
